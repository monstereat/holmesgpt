# 生产级 AIOps 事故诊断项目路线图

## 目标

把当前可启动的 OpenObserve + HolmesGPT 演示扩展成可部署、可运维、可受控执行生产动作的事故诊断平台：生产告警进入系统，调查任务可靠执行并持久化，HolmesGPT 返回可核验的日志/Trace 证据，操作人员可审批并由授权执行器处理白名单动作，系统验证结果并完成复盘。

当前阶段：**提案待确认**。未经用户批准 Spec 和 Plan，不开始业务代码或数据库变更。

## 范围原则

- HolmesGPT API、Agent 和工具集继续使用 Python/FastAPI；在现有 `server.py` API 边界扩展，不新增重复的 NestJS 控制面。
- 保留 NestJS order-service 作为可控故障源；OpenObserve 仍负责遥测数据存储和检索。
- 推荐以 PostgreSQL 保存事故/任务元数据，以 Redis + Celery 执行可重试的调查任务；这是待 Plan 验证的方案，schema/migration 必须经用户单独授权。
- 调查与执行权限分离。生产写操作必须由动作拥有方授权的独立执行器执行；没有批准、权限或白名单匹配时不得产生副作用。
- 真实模型和 OpenObserve 凭据只通过用户运行环境提供，不提交到仓库。
- 生产目标平台、身份提供方、动作清单、SLO、数据保留与合规约束未确认前，不批准实施 Plan。

## 切片与验收

### R01：持久化事故与可靠任务

- 状态：待 Spec 批准
- 范围：告警认证/校验、稳定幂等键、事故与任务 API、PostgreSQL 状态存储、Celery/Redis 队列、退避重试、超时与重启恢复。
- 验收：重复告警复用事故/任务；API 或 worker 重启后状态可恢复；临时失败按上限重试并留下最终结果；未授权请求拒绝。
- 前置门槛：Spec 和 Plan 批准；PostgreSQL schema/migration 获得明确授权。

### R02：真实 Holmes 只读调查

- 状态：待 R01 和凭据
- 范围：队列 worker 调用现有 Holmes 调查能力；OpenObserve 使用只读账户和流白名单；将调查结论、Trace ID、查询范围及证据链接保存到任务记录。
- 验收：真实告警能完成 Holmes 查询；每个确定性结论能对应可复查的证据；无证据内容标记为假设；调查工具无写权限。
- 前置门槛：模型凭据、OpenObserve 地址/只读账户、受限流配置。

### R03：事故查看界面和演示闭环

- 状态：待 R01/R02
- 范围：在现有演示入口展示事故列表、状态、Trace、调查结果、重试与时间线；完善一条可复现故障的启动和演示说明。
- 验收：新开发者按文档本机启动；能从订单故障看到告警、调查状态、证据和最终结果；错误、超时和空结果有清晰状态。

### R04：Roadmap 集成、确定性评测和简历材料

- 状态：待 R02
- 范围：接入选定 Git/CI 发布事件和 Runbook；确认 Keep 或自建聚类；将现有 20 个合成证据案例接入回放/评测 harness；统计检索、诊断、证据引用、误处置和聚类误合并；产出架构说明及真实验证数据。
- 验收：发布/事故/任务/Trace 可互查；评测可重复运行；报告区分 mock 与 live 结果；简历描述只引用已测得数据，不杜撰准确率或性能数字。
- 前置门槛：集成提供方、隔离测试环境、模型凭据和双方确认的评测阈值。

### R05：生产部署与受控执行

- 状态：待生产约束确认和前置切片
- 范围：目标平台部署、密钥/网络/RBAC、健康探针、容量与告警、数据库备份恢复、升级/回滚；动作白名单、动作拥有方授权、人工审批、幂等、取消、审计、执行后验证与失败回退。
- 验收：在隔离预生产环境通过发布/恢复演练；动作权限矩阵和安全测试通过；生产执行只对明确授权动作开放。
- 前置门槛：平台、身份提供方、SLO/保留合规、允许动作清单、动作拥有方接口及生产执行授权。

## 安全边界与待确认项

- 不开放无审批的任意 Agent 生产写操作；仅实现明确的白名单动作，并由其拥有方重新授权。
- 不因简历技术广度新增 Java、Go 或重复 NestJS 业务 API。
- 生产部署目标、身份/租户/RBAC、SLO、数据保留/合规要求、Git/CI 提供方、Keep 选择、生产动作和回退标准均待用户确认。
- 具备部署配置不等于已发布到生产；发布和真实生产操作分别需要用户明确授权。

## 依赖关系

`R01 → R02 → R03 → R04 → R05`。R01 需先确认持久化数据边界和 schema 授权；R02、R04 依赖外部凭据；R05 依赖生产环境、动作清单和动作拥有方接口。
